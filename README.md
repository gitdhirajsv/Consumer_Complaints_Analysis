# Comcast Consumer Complaints Analysis

This project provides a professional-grade analysis of consumer complaints against Comcast Telecom. It utilizes advanced data science techniques, including sentiment analysis and interactive visualizations, to derive business intelligence from customer feedback.

## Key Features
- **Temporal Analysis**: Detailed breakdown of complaint volumes by month and day of the week.
- **Geographic Intelligence**: State-wise distribution of complaints visualized through interactive choropleth maps.
- **Sentiment Profiling**: Quantitative analysis of customer frustration levels using NLP (TextBlob).
- **Interactive Dashboards**: Modern visualizations built with Plotly for dynamic data exploration.
- **Resolution Tracking**: Analysis of case status (Open vs. Closed) by geographic region.

## Requirements
To run this notebook, install the following libraries:
```bash
pip install pandas numpy matplotlib plotly textblob
```

## Dataset
The analysis is based on the `Comcast_telecom_complaints_data.csv` dataset. Ensure this file is present in the same directory as the notebook.

## Usage
Simply open the `Consumer_Complaints_Analysis.ipynb` in any Jupyter environment (JupyterLab, VS Code, or Google Colab) and execute the cells.
